## Design specificity

Grounded in the product where it counts — CSV plan import reading real spreadsheet columns, calendar-correct 9-week phasing, carry-forward, deadline-based timer surviving iOS suspension. Not grounded in the visual system: ink-black + arctic blue + liquid glass would sit unchanged on a sleep tracker or a crypto app. The detector agrees from the other direction, flagging `ai-color-palette` (cyan neon on dark) four times plus a cyan gradient background twice.

Worse, the surface contradicts the domain: the grid is hard-coded KG and REPS, so this owner's own plan (Plank 3x30s, Side Plank 3x30s each, Pallof Press 3x10 each) logs as weighted reps. Progress reports "Plank — best set 70x10, est. 1RM 93.3 kg". The owner runs; Treadmill/Rowing/Stair Climber ship in the library with no way to log any of them.

## What's working

1. The plan pipeline: real CSV in, 9 weeks of Full Body -> PPL on a correct Mon-Sun calendar, targets/RPE/coaching notes carried to the set rows, DST-safe calendar arithmetic.
2. Typographic hierarchy on the set row: tabular figures, 17px/650 inputs against 10.7px micro-labels, a 5-column grid that never reflows.
3. Timer engineering: deadline-based, persisted, restored on reload, visibilitychange re-check, scaleX not width, wake lock.

## Priority issues

P0 — Completing a set produces no visual change. completeSet() adds `set-done` to the row but never toggles `on` on the check button; `.on` is applied only at build time (train.js:381). Measured after tap: `.set-row.set-done` = 2, `.set-check.on` = 0, aria-label still "Complete set". Reproduced 4/4 runs across both themes and widths. Row background/border/colour/opacity delta between done and open: 1.000:1 — identical. The entire difference is one 1px input border at 1.78:1. The designed delta is 11.68:1 and is never reached until something else re-renders. Tapping again un-logs the set, which is exactly what a user does when the first tap appears to do nothing.

P1 — --text-3 fails WCAG AA everywhere. Dark 3.43-3.78:1, light 2.52-2.97:1, at 9.6-13px. This is SET/PREVIOUS/KG/REPS, set numbers, REST caption, tab labels, entry-sub, field hints, picker meta. The disabled `.set-prev` dash lands at 1.65:1 dark / 1.54:1 light. The column you most need mid-set — the number you are trying to beat — is the least legible thing on the card.

P1 — Light mode: achievement colour collides with destructive, and the tick glyph fails. `--ember` #C4441A vs `--danger` #C22B3E = 1.13:1, so "Personal best" reads as an error. `.set-check.on` and `.chip-on` hard-code `color:#01121F` while `--accent` flips dark in light mode: glyph contrast 2.80:1. `.sheet-close` 2.97:1 fails the 3:1 non-text floor.

P1 — A live workout is invisible outside Train, and the app offers buttons that can only fail. During an active session Plan renders "Start today's session" as a full-width primary plus 7 enabled week Start buttons; every one produces an error toast. Nothing marks the session as live.

P2 — Tap targets below the 44pt floor. `.set-prev` 66x19 (50x19 at 320px), `.rest-pill` 56x28, `.rest-adjust` 52x37, `.rest-skip` 55x37, `.icon-btn` 38x38, `.sheet-close` 40x40, `.sched-start` 60x32, `.btn-sm` blocks 36 tall, `.set-index` 32 wide. P2 — Finishing a workout has no ending. Forty minutes collapses into a 2.6s toast over a screen headed "Ready to train", with "Repeat this workout" offered for the session finished four seconds earlier. A full rise cascade animates the start screen nobody looks at.

## Persona red flags

Impatient power user: every accelerator stops one step short — enterkeyhint with no handler, a 19px-tall copy-previous target, a 78-item alphabetical picker when the app knows today's four exercises, and no confirmation that a set landed.

Distracted mobile user: no current-set marker, no session progress ("2 sets" never "2 of 12"), the set-index doubles as an undiscoverable warm-up toggle whose only affordance is a title attribute iOS never renders — and toggling it renumbers every set below, which looks like data loss.

Accessibility-dependent user: contrast fails across the primary screen in both themes; sheets declare role=dialog aria-modal but never move focus in or restore it on close; focus outlines are replaced by a 1.5:1 border; the timer's urgency blink is suppressed under prefers-reduced-motion with no substitute.
